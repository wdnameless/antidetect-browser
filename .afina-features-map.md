# Afina Browser — полная карта функционала (167 страниц docs, краул 2026-08-31)

## 1. Аккаунты/Профили
- Таблица аккаунтов с колонками, фильтрами, сортировкой, поиском
- Массовое создание: форма + импорт Excel
- Массовое изменение отпечатка (bulk fingerprint update): timezone, языки, CPU/RAM, шум компонентов
- Смена UserAgent и ядра браузера (комбинированный режим)
- Дублирование (одиночное и массовое), перенос из других браузеров
- Доп. данные (ключ/значение) + Зашифрованные данные (AES-256-CBC), экспорт/импорт XLSX
- Очистка кэша (одиночная/массовая/авто), удаление данных расширений
- Cookie Robot: авто-навигация по URL для прогрева cookies
- Вход по токену (login by token), массовая очистка токенов
- Экспорт в TXT (аккаунты+cookies), экспорт cookies JSON (массовый), импорт из TXT
- Импорт аккаунтов из других браузеров
- Восстановление из бэкапа (restore-from-backup)
- Группы (папки) аккаунтов с логикой, назначение групп/тегов/прокси массово

## 2. Прокси
- Отдельный раздел Прокси: таблица, CRUD, группы
- Типы, массовое добавление текстом
- Импорт/экспорт Excel
- Чекер прокси (индивидуально и для выделенных)
- Назначение на аккаунты массово
- Системный прокси приложения + глобальная маршрутизация + диагностика сети

## 3. Расширения
- Отдельный раздел: добавление по URL Chrome Web Store или .zip
- Вкл/выкл, закрепление, обновление из магазина, удаление данных расширений
- Привязка к профилю (вкладка расширений в редактировании) и к группам

## 4. Автоматизация / Скрипты
- Визуальный конструктор скриптов (canvas, блоки, авто-соединение, headless, пошаговый режим, работа без браузера, переменные окружения, логи)
- RPA-модули (переиспользуемые подпрограммы с AI-контекстом, экспорт/импорт)
- Папки/теги/избранное/хэши скриптов и модулей
- Задачи и группы задач: лимиты, retries, перемешивание, расписание, папки
- Активные задачи: таблица процессов, логи, стоп/рестарт
- Триггеры: папки, таблицы, топ-панель
- Центр автоматизации: каталог готовых скриптов/модулей, фильтры, 1-клик загрузка
- HTTP API: 11 модулей (профили, переменные, скрипты, модули, базы, глобальные переменные, задачи, прокси, cookies+CDP, браузер, ...)
- MCP-сервер (AI-агенты): инструменты, ресурсы, сценарии
- Синхронизатор: зеркалирование, выравнивание мониторов, массовая работа с вкладками, горячие клавиши

## 5. Команды/Облако
- Команды, роли, разрешения, переключение пространств
- Afina Cloud: перенос аккаунтов, экспорт в облако, импорт из облака
- Google Drive: синхронизация скриптов/модулей/настроек/бэкапов, автобэкап
- Telegram-интеграция (бот, уведомления, права)
- Afina AI (ChatGPT API, прокси для AI, чат)
- Мультидевайс (работа на нескольких ПК)

## 6. Данные/Безопасность
- Почта: Afina Mail (IMAP), credential manager, переадресация
- Ключи шифрования: файл ключей, мастер-пароль, перенос устройства
- Интеграционные ключи (Dolphin, AdsPower, Vision X)
- Базы данных: локальные SQL-таблицы, конструктор, SQL-терминал, импорт/экспорт
- Бэкапы: локальные (политика частоты/ retention), Google Drive, логи бэкапов
- Автоблокировка по таймеру, полное шифрование, проверка целостности расширений
- Защита от захвата экрана (screen capture protection)
- Логи раздел, основная папка проекта, языки интерфейса, zoom UI, горячие клавиши
- Экспорт/импорт настроек (локально и Google Drive)

## 7. Разное
- Реферальная система, история заказов, лицензии (внутри профиля)
- Покупка/продление: Telegram-бот, промокоды, смена тарифа
- Экспорт/перенос на другой ПК (Google Drive / архм)
- Гайды по DNS на роутерах, perfect fingerprint (консоль, CPU/RAM)
- Загрузка закладок в профили, стартовые страницы, аргументы запуска, WebRTC режимы
