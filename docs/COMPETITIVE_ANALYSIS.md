# Конкурентный анализ: AdsPower, Dolphin Anty vs наш MVP

Сравнение с лидерами рынка антидетект-браузеров и **критические фичи, которых у нас нет**.

## Что у нас уже есть (сильные стороны)
- **AdsPower-совместимый Local API** — у AdsPower API платный, у нас включён по умолчанию. Автоматизация через CDP (Puppeteer/Playwright/Selenium).
- **Kernel-level stealth**: `webdriver=false`, уникальные canvas/WebGL на профиль. По заявлению ядра — pass CreepJS/PixelScan/BrowserScan/Turnstile.
- **WebRTC полностью отключён** → UDP-утечки исключены (у AdsPower это опция «WebRTC Disabled»).
- Прокси HTTP/HTTPS/SOCKS5/SSH + авторизация через CDP + авто-timezone.
- Смена девайса (десктоп ядром, мобильные CDP-эмуляцией).
- Устанавливаемый Windows-MVP, бесплатно, без подписки.

> Примечание: по данным независимого обзора (GoLogin, янв 2026), **Dolphin Anty был детектирован чекером IPhey** — т.е. наше ядро fingerprint-chromium потенциально ** stealth-сильнее Dolphin Anty**.

## Критические фичи рынка, которых у нас НЕТ

### Tier 1 — критично для реальных сценариев (высокая ценность, реализуемо)
| Фича | Есть у | У нас | Усилия |
|---|---|---|---|
| **Расширения Chrome Web Store** (per-profile) | AdsPower (SunBrowser), Dolphin | ❌ нет | **Низкие-средние** (`--load-extension` + UI) |
| **Cookie import/export** | AdsPower, Dolphin | ❌ (колонка в БД есть, API/UI нет) | Средние |
| **Geolocation-спуфинг** | AdsPower | ❌ (колонка есть, не подключено) | **Низкие** (CDP `setGeolocationOverride`) |
| **Batch/bulk-операции** (массовое создание/импорт профилей) | AdsPower (до 1000/батч), Dolphin | ❌ (только по одному) | Средние |

### Tier 2 — важно для полноты stealth (средние-высокие усилия)
| Фича | Есть у | У нас | Усилия |
|---|---|---|---|
| **50+ тюнюемых параметров фингерпринта** (WebGPU, IndexedDB, fonts, audio) | AdsPower | ⚠️ частично (seed + platform/brand/cores/tz/lang) | Средние (раскрыть больше флагов ядра) |
| **Firefox-ядро** (FlowerBrowser) | AdsPower | ❌ (только Chromium) | Высокие (нужен Firefox-билд; вариант — Camoufox) |
| **TLS/сетевой фингерпринт** (JA3/JA4) | AdsPower (network) | ❓ не подтверждено | Высокие/неизвестно |
| **Нативная мобильная эмуляция** (iOS/Android на уровне ядра) | AdsPower | ⚠️ CDP-эмуляция (слабее: только UA/touch/screen) | Высокие |

### Tier 3 — команда/масштаб/коммерция (нужно только при мульти-юзере)
| Фича | Есть у | У нас | Усилия |
|---|---|---|---|
| **Cloud sync / кросс-девайс профили** | AdsPower | ❌ (локально, одна машина) | Высокие |
| **Команда**: роли, права, шеринг профилей, логи | AdsPower, Dolphin | ❌ (single-user) | Высокие |
| **RPA no-code автоматизация** + **Multi-Window Synchronizer** | AdsPower, Dolphin | ❌ (у нас только API — гибче для power-user, но нет no-code UI) | Высокие |
| Автообновление ядра/приложения, подпись кода, security-сертификаты (SOC2/ISO) | AdsPower | ❌ | Средние-высокие |

## Рекомендуемый порядок закрытия гэпов
1. **Расширения** (низкие усилия, высокая ценность для рабочих сценариев).
2. **Cookie import/export** (критично для фарма аккаунтов).
3. **Geolocation-спуфинг** (низкие усилия).
4. **Batch-операции** (масштабирование).
5. Раскрытие доп. параметров фингерпринта (WebGPU/IndexedDB/fonts).
6. Firefox-ядро / нативная мобильная эмуляция / TLS — по необходимости.
7. Cloud/team/RPA — только если инструмент станет мульти-юзерным/коммерческим.

## Вывод
По **stealth-ядру и автоматизации** мы на уровне или выше Dolphin Anty и ближе к AdsPower. Главные практические гэпы — **расширения, cookie import/export, geolocation, batch** (Tier 1): они реализуемы за обозримые усилия и дают наибольшую ценность. Командные/облачные фичи (Tier 3) — это уже другой продукт (мульти-юзерный SaaS), а не персональный инструмент.
